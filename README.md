# 전국 문화생활 플랫폼 (아임웹 위젯)

전국 축제·행사·공연·전시 데이터를 모아서 **이달의 추천**을 보여 주고, 지역·날짜·장르·조건으로 검색하고, **찜**하거나 **내 일정(캘린더)**에 담을 수 있는 웹 서비스입니다.
아임웹 "코드" 위젯에 붙여 넣어 바로 쓸 수 있고, 비용은 **무료 한도 안**에서만 듭니다.

---

## 1. 구조 (0원 운영)

```
 [TourAPI]  [KOPIS]  [서울 열린데이터]
      \        |        /
   GitHub Actions (6시간마다 자동 실행, 무료)
     collector/collect.mjs  ─ 수집 → 통일된 형식으로 변환 → 중복 제거
              │
   docs/data/events.json  ── GitHub Pages로 공개 (무료 정적 호스팅)
              │
   아임웹 코드 위젯 (widget/imweb-widget.html) ─ 방문자 브라우저가 JSON 한 개만 읽음
```

이렇게 만든 이유:
- **API 키가 노출되지 않음.** 키는 GitHub Secrets에만 있고, 방문자에게는 결과 JSON만 갑니다.
- **CORS·http 문제가 없음.** KOPIS(XML)와 서울시 API(http, 8088 포트)는 아임웹(https) 페이지에서 바로 부를 수 없습니다. 서버에서 모아 두면 이 문제가 사라집니다.
- **호출 한도를 지킴.** 방문자가 많아도 공공 API 호출 수는 늘지 않습니다(6시간에 한 번만 호출).
- **서버 비용 0원.** 공개 저장소에서는 Actions와 Pages가 무료입니다.

| 항목 | 무료 한도 | 이 프로젝트 사용량 |
|---|---|---|
| GitHub Actions (공개 저장소) | 무제한 | 1회 1~3분 × 하루 4회 |
| GitHub Pages | 사이트 1GB, 월 100GB 트래픽(권장치) | JSON 1~2MB (압축 전송 시 약 300~500KB) |
| TourAPI 개발계정 | 하루 1,000건 | 목록 1~3건 + 상세 150건 × 4회 = 하루 약 610건 |
| KOPIS | 무료 | 목록 수십 건 + 새 공연 상세만 조회 |
| 서울 열린데이터광장 | 무료 (1회 최대 1,000건) | 회당 약 5~8건 |

요금·연령·주소 같은 상세 정보는 매 실행마다 **새로 생긴 행사만** 조금씩 조회하고 `cache/enrich.json`에 저장해 다시 씁니다. 그래서 첫날에는 일부 행사에 요금이나 연령 정보가 비어 있다가 하루이틀 안에 채워집니다.

## 2. 설치 순서

### ① API 키 발급 (모두 무료)

| 출처 | 신청하는 곳 | 비고 |
|---|---|---|
| 한국관광공사 TourAPI | 공공데이터포털(data.go.kr)에서 **"한국관광공사_국문 관광정보 서비스_GW"** 활용신청 | 마이페이지의 **일반 인증키(Decoding)** 값을 사용. 보통 바로 승인됩니다. |
| KOPIS | kopis.or.kr → 공연예술DB → **Open API** → 서비스키 신청 | 이메일로 발급 |
| 서울시 문화행사 | data.seoul.go.kr → **"서울시 문화행사 정보"** → 인증키 신청 | 일반 인증키 |

> 키가 없는 출처는 자동으로 건너뜁니다. TourAPI 하나만 먼저 넣어도 동작합니다.

### ② GitHub 저장소 만들기
1. github.com에서 **공개(Public)** 저장소를 만듭니다. 예: `kculture`
2. 이 폴더의 파일을 그대로 올립니다(`.github`, `collector`, `docs`, `widget`, `README.md`).
3. **Settings → Secrets and variables → Actions → New repository secret**에 아래 이름으로 키를 등록합니다.
   - `TOUR_API_KEY`, `KOPIS_API_KEY`, `SEOUL_API_KEY`
4. **Settings → Pages**: Source는 `Deploy from a branch`, Branch는 `main`, 폴더는 `/docs`로 저장합니다.
5. **Actions 탭 → "문화행사 데이터 수집" → Run workflow**로 첫 수집을 실행합니다. 1~3분 뒤 `docs/data/events.json`이 생깁니다.
6. `https://<내아이디>.github.io/kculture/`에 접속하면 위젯 미리보기가 나옵니다.

### ③ 아임웹에 붙여넣기
1. `widget/imweb-widget.html`을 열고 위쪽의 아래 줄에 데이터 주소를 넣습니다.
   ```html
   <div id="kc-app" data-data-url="https://<내아이디>.github.io/kculture/data/events.json"></div>
   ```
2. 아임웹 디자인 모드에서 원하는 섹션에 **위젯 추가 → 코드(HTML)** 위젯을 넣고, 파일 내용 **전체**를 붙여넣습니다.
3. 섹션 너비는 "넓게(전체)"를 권장합니다. 위젯이 최대 1200px 안에서 반응형으로 맞춰집니다.
4. 저장한 뒤 **사이트 미리보기**에서 확인합니다. 디자인 모드 편집 화면에서는 스크립트가 실행되지 않을 수 있습니다.

> 주소를 비워 두면 **샘플 데이터**로 동작하므로, 키 발급 전에도 디자인을 먼저 확인할 수 있습니다.

## 3. 기능

| 영역 | 내용 |
|---|---|
| **추천** | **○월의 추천**(이번 달 진행·시작 행사 중 장르가 고르게 섞이도록 12개, 매달 순서가 바뀜), **이번 주말 어디 갈까?**, **곧 끝나요**(7일 안에 마감). 지역을 고르면 그 지역 기준으로 바뀝니다. |
| **지역 필터** | 시·도 17개 → 시·군·구(실제 데이터에 있는 곳만, 건수 함께 표시) |
| **날짜 필터** | 전체 / 오늘 / 이번 주말 / 이번 주 / 이번 달 / 기간 직접 선택 |
| **장르 필터** | 축제, 콘서트, 뮤지컬, 연극, 클래식, 국악, 무용, 전시, 체험·행사, 기타 (여러 개 선택 가능, 장르별 건수 표시) |
| **조건 필터** | 무료만 / 실내·야외 / 관람 연령(전체관람가, 만 5·8·13세 관람 가능) |
| **검색·정렬** | 행사명·장소·지역 검색, 추천순·가까운 일정순·마감 임박순·이름순 |
| **카드** | 포스터, D-day·마감 임박·무료 배지, 하트(찜) |
| **상세 팝업** | 기간·장소·주소·요금·연령, 상세/예매 링크, 카카오맵, **내 일정에 추가**(날짜 선택), 구글 캘린더, .ics 파일, 공유 링크(`#kc=ID`로 바로 열림) |
| **캘린더 탭** | 월 달력에 내 일정과 그날 시작하는 행사 수 표시. 날짜를 누르면 그날 열리는 행사 목록이 나오고, 다가오는 일정은 .ics 파일로 한꺼번에 받을 수 있음 |
| **찜 탭** | 찜한 행사 모음 (데이터가 갱신되어도 유지) |
| **기억하는 것** | 찜·일정·마지막 필터를 방문자 브라우저(localStorage)에 저장. 로그인이 필요 없습니다. |

### 데이터 정규화 규칙
- **장르**: KOPIS `genrenm`, 서울 `CODENAME`을 10개 장르로 통일했습니다. TourAPI 행사는 모두 "축제"로 분류됩니다.
- **무료 여부**: 서울은 `IS_FREE` 값을 씁니다. TourAPI는 `usetimefestival`, KOPIS는 `pcseguidance` 문구를 분석합니다("무료"가 있고 "○○원"이 없으면 무료).
- **관람 연령**: "만 7세 이상", "36개월 이상", "전체관람가", "청소년관람불가" 같은 문구를 숫자로 바꿉니다.
- **실내/야외**: API에 해당 항목이 없어서 장소 이름으로 **추정**합니다(극장·홀·미술관 → 실내, 공원·광장·해변·일원 → 야외). 위젯에도 "일부 추정"이라고 안내합니다.
- **시·군·구**: TourAPI는 주소에서, 서울은 `GUNAME`에서, KOPIS는 공연장 상세(`prfplc`) 주소에서 뽑습니다.
- **중복 제거**: 서울시 데이터와 KOPIS에 같은 공연이 있으면 제목과 시작일로 묶고, 이미지·요금 정보가 많은 쪽을 남깁니다.
- 한 출처의 API가 실패하면 **직전 수집분을 유지**해서 화면이 비지 않습니다. 실패 내용은 `events.json`의 `sources`에 기록됩니다.

## 4. 벤치마킹 반영

| 서비스 | 참고한 점 | 이 위젯에 반영한 것 |
|---|---|---|
| 대한민국 구석구석 (한국관광공사) | 축제 달력, 지역·월별 탐색 | 시·도 → 시·군·구 2단계 필터, 캘린더 탭 |

| 네이버 공연·전시 검색 | 지역·기간·장르 칩 필터, 진행 중/예정 표시 | 칩 필터와 진행중·예정 배지, 선택한 필터를 칩으로 보여 주고 바로 해제 |
| 서울문화포털 | 무료·유료, 이용 대상 구분 | 무료만 보기, 관람 연령 필터 |
| 트리플, 마이리얼트립 | 찜, 일정에 담기 | 하트 찜, 날짜를 골라 일정에 담기 |
| 각종 예매 앱 | 외부 캘린더 내보내기, 공유 | 구글 캘린더, .ics, 공유 링크 |
| 모바일 커머스 공통 | 필터 접기, 가로 스크롤 추천 | 모바일에서는 "필터" 버튼으로 접고, 추천은 가로로 넘기는 형태 |

## 5. 추가 데이터 출처 검토 (다음 단계 후보)

| 후보 | 채워 줄 부분 | 판단 |
|---|---|---|
| 한국문화정보원 「공연전시정보 조회서비스」(문화포털, data.go.kr) | **전국 전시** (KOPIS에는 전시가 없음) | 1순위. 현재 전시는 서울 데이터에만 있습니다. 같은 수집기 방식으로 출처 하나만 더하면 됩니다. |
| 경기데이터드림 「문화행사 현황」 | 경기도 시·군 행사, 체험 | 2순위. 경기 지역 이용자가 많다면 추가 |
| 부산·대구·인천 등 시·도 공공데이터 축제/행사 | 지역 소규모 행사 | 필요한 지역만 선택해서 추가 |
| 국립현대미술관·국립중앙박물관 전시 API | 주요 국립 전시 | 전시 보강용 |
| 카카오맵 JavaScript SDK (무료 한도) | 지도에서 보기, 내 주변 | 좌표는 이미 수집하고 있으므로 지도 탭만 만들면 됩니다 |

새 출처를 더할 때는 `collector/collect.mjs`에 `collectXXX()` 함수를 하나 추가해 같은 형식의 이벤트를 반환하게 하고, `sources` 배열에 등록하면 됩니다.

## 6. 개인 캘린더 (다음 단계)
지금은 찜과 일정이 **방문자의 브라우저에만** 저장되므로 기기가 바뀌면 이어지지 않습니다. 요청하신 대로 개인 캘린더 서버 연동은 데이터 연동 이후에 하는 것으로 남겨 두었습니다. 무료로 할 수 있는 방법은 다음과 같습니다.
- **Supabase 무료 플랜**: 로그인(카카오·구글)과 DB를 무료로 제공하므로 찜·일정을 계정 단위로 저장할 수 있습니다. 위젯의 `LIKES`와 `PLANS` 저장 부분만 바꾸면 됩니다.
- 아임웹 회원 정보와 연동하려면 아임웹 API 사용 가능 여부(요금제)를 먼저 확인해야 합니다.

## 7. 파일 구성

| 파일 | 역할 |
|---|---|
| `widget/imweb-widget.html` | **아임웹에 붙여 넣는 최종 코드** (HTML·CSS·JS 한 파일, 외부 라이브러리 없음, 폰트는 Pretendard CDN) |
| `collector/collect.mjs` | 수집·정규화·중복 제거·상세 보강 (Node 20, 설치할 패키지 없음) |
| `collector/normalize.mjs` | 지역·장르·무료·연령·실내외 판정 규칙 |
| `collector/build-preview.mjs` | 위젯으로 `docs/index.html` 미리보기 페이지 생성 (`--demo` 옵션은 샘플 데이터 사용) |
| `.github/workflows/collect.yml` | 6시간마다 자동 수집하고 커밋 |
| `docs/` | GitHub Pages 공개 폴더 (`index.html` 미리보기, `data/events.json`) |
| `cache/enrich.json` | 상세 정보 누적 캐시 (자동 생성) |

### 위젯을 고친 뒤
`widget/imweb-widget.html`을 고쳤다면 아임웹 코드 위젯에도 다시 붙여넣고, `node collector/build-preview.mjs`로 미리보기 페이지도 갱신하세요.

### 자주 묻는 문제
- **"데이터를 불러오지 못했어요"**: `data-data-url` 주소를 브라우저에서 직접 열어 보세요. Pages가 켜져 있는지, 첫 수집이 끝났는지 확인하면 됩니다.
- **Actions 로그에 `SERVICE_KEY_IS_NOT_REGISTERED_ERROR`**: TourAPI 키가 Encoding 값이거나, 활용신청이 아직 반영되지 않은 상태입니다. Decoding 키를 쓰고 1시간쯤 뒤 다시 실행하세요.
- **이미지가 안 보임**: 일부 출처의 이미지 서버가 https를 지원하지 않는 경우입니다. 이때는 장르 색상 카드로 자동 대체됩니다.
- **저장소에 60일 동안 활동이 없으면** GitHub가 예약 실행을 멈출 수 있습니다. 자동 커밋이 계속되면 대개 문제없지만, 멈췄다면 Actions 탭에서 다시 켜세요.
